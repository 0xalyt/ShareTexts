Leave a note or link for later

Create a Temporary Space, share its eight-character code, and save what you need before it closes.

A Temporary Space keeps text and links on the server while people come and go. Use it for workshop links or a collection of trip links. For a handoff while both devices are open, use a live room instead.

Create a space

  1. Choose a code

    Open the space creation page. Enter an eight-character code or generate one. If it is taken, choose another.

  2. Choose how long it stays open

    Pick a lifetime from 6 hours to 7 days. The countdown starts when you create the space.

  3. Add content

    Create the space, then add text or links. File uploads are not currently available in Temporary Spaces; send files through a live room instead.

Invite the people who need it

Share the eight-character code or the space link. Recipients open the space join page, enter the code, and choose Join space. They can add text and links or copy what is already there.

A code gives access. Anyone with a working code or link can join while the space is open. Do not publish it unless you intend to give that audience access. Space content is server-stored; it is not hidden from the service.

Come back before it closes

The creator does not need to keep a tab open for others to use the space. Copy anything you need before the expiry shown in the space. If offered, a reminder is optional and requires browser notification permission.

Close it when you are finished

The creator can close the space early. Otherwise, it closes at expiry. Access ends and the code and link stop working. Server content enters a deletion process, which may need to retry.

Closing a space cannot remove copies someone has already made. A space is not a permanent backup. Keep your own copy of important content.

If a code will not work

Check that you are on the space join page, not the live-room Receive screen. Ask the creator to confirm the code and whether the space is still open. An expired invitation cannot reopen a closed space.

Read the Privacy Policy for storage and connection details.

Questions before you create a space

Do I need to keep the space open?

No. The content stays on the server until the chosen lifetime ends or the creator closes the space.

Can I leave a file in a space?

Temporary Spaces currently accept text and links. Use a live room for files.

Who can join?

Anyone with a working code or link can join while the space is open. Share invitations only with the people you intend to include.

How to send files from Android to iPhone

Open sharetexts.online on both phones. Tap Send on the Android phone, then enter the six digits on the iPhone. Choose the file. It appears on the iPhone with a Save button. Both phones need a browser and an internet connection, and both tabs must stay open while the file moves.

Quick answer: open sharetexts.online on both devices, tap Send on one, type the six-digit code on the other, pick the file. It arrives with a Save button.

What actually moves

Photos, videos, PDFs, documents, links and plain text. Android hands over the file as it is stored, so a 4K video stays a 4K video. The iPhone saves it into Files or Photos, depending on where you open it from.

Step by step

  1. Open the site on both phones

    Chrome on Android, Safari on iPhone. Both go to sharetexts.online.

  2. Tap Send on the Android phone

    A six-digit code appears. Keep the screen on.

  3. Enter the code on the iPhone

    Tap Receive, then type the six digits. The two phones connect directly.

  4. Send, then save

    Pick the photos or files on Android. On the iPhone, tap Save on each item.

Why not just use a cloud drive

A cloud drive makes you upload, wait, then download. That is three steps and a copy that outlives the transfer. This is one connection and no stored copy: when both tabs close, the room is gone.

Where the two platforms disagree

Safari on iOS pauses a tab when you switch apps, so the iPhone side must stay visible while a large file arrives. Android can keep the tab alive in the background more reliably. If a transfer stalls, bring the iPhone tab back to the front and it resumes.

Questions people ask

Do both phones need the app?

No app is involved on either side. Both phones use their own browser.

Can the iPhone send back to the Android phone?

Yes. Either device can create the room, and either can send once they are connected.

Do Live Photos keep their motion?

A Live Photo arrives as a still image plus its video component only if the picker offers both. The simplest reliable result is the still image.

Is there a size limit?

There is no fixed limit in the product. Real limits are the phone's memory and the patience of the network, so very large videos are better sent one at a time.

Does it work between an old Android and a new iPhone?

Yes, as long as both browsers support WebRTC. Chrome 80 or later and iOS 14 or later both do.

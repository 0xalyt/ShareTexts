Pick a browser for your transfer

What to check on iPhone, Android, Windows, Mac, and other devices before a browser transfer.

Use an up-to-date browser

Start with Chrome, Safari, Firefox, or Edge. ShareTexts is designed for iPhone, iPad, Android, Windows, macOS, Linux, and ChromeOS. The devices do not need the same operating system.

Live rooms need browser support for WebRTC connections. Hop also needs browser encryption and storage features. Private-browsing settings and extensions can limit these features, so support is not a promise for every browser configuration.

On a phone or tablet

Keep ShareTexts visible and the screen awake during a live transfer. The system may suspend a tab when you switch apps or lock the device. Open the link in your regular browser if a browser inside a messaging app cannot connect.

Use the download control after receiving a file, then check Downloads or Files. Give camera permission only if you want to scan inside the browser; typing the code works without it.

On a computer

Keep the receiving tab open until the file completes. Check available disk space before a large transfer. Allow the browser's download prompt, then open the received copy to check it.

On a work or guest network

Some networks block direct connections or device discovery. Nearby is optional: use the current six-digit code or a room link if the other device is not listed. If the connection still fails, follow your organization's network policy rather than disabling its protections.

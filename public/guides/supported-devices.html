Supported Devices

ShareTexts works on any two devices with a modern browser. No app installation required.

The short answer: If your browser supports WebRTC (which all modern browsers do), ShareTexts works. iPhone, Android, Windows, macOS, Linux — any combination.

Tested Combinations

These specific cross-platform transfers have been tested and verified:

iPhone → Windows PC — Safari on iOS, Chrome on Windows

Android → Mac — Chrome on Android, Safari on macOS

Windows → Android — Chrome on both

Mac → iPhone — Safari on both

Linux → iPhone — Chrome on Linux, Safari on iOS

Requirements

  • Internet connection — both devices must be online during the transfer
  • Modern browser — Chrome 60+, Safari 15+, Firefox 60+, Edge 79+
  • JavaScript enabled — required for ShareTexts to function
  • WebRTC support — all modern browsers include this

What Doesn't Work

  • Internet Explorer (any version)
  • Very old mobile browsers without WebRTC support
  • Offline devices (both must be online for initial pairing)

Honest fallback: ShareTexts checks what your browser can do before it starts. If WebRTC or other required features are missing, you see a clear explanation instead of a broken page — and any other browser on the same device will work.

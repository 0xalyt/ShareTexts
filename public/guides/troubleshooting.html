Get a transfer moving again

Find the next step for a rejected code, missing Nearby device, stalled file, or closed space.

Keep the original file. Copy unsent text before refreshing a tab, and avoid creating rooms repeatedly if the service is unavailable.

The code is not accepted

Use the current six digits on the sending device, not a screenshot of an older code. Choose Receive on a different device or browser profile. Another tab in the same profile is not a separate device.

An eight-character code belongs to a Temporary Space. Enter it at the space join page, not the live-room screen. Ask the creator whether the space is still open.

Nearby does not show my device

Turn Nearby on for 10 minutes on the device you want to send to. Keep both devices on the same network and out of a room while discovering.

Guest networks, VPNs, or a hosting configuration can prevent discovery. Use a code, QR scan, or room link instead. Do not weaken a workplace network's security settings to make discovery work.

The file stops progressing

Bring both tabs to the foreground and keep the screens awake. Check that both devices still have internet access. If the transfer reports failure, use Retry.

Try a small file. If that works but a large file does not, check available storage and browser limits. Keep the original rather than assuming a partial download is complete.

The file is not in Downloads

Receiving and downloading are separate steps. Use the file's download control and allow downloads if asked. Check the browser's downloads list or your phone's Files app.

The room will not open

Check whether other websites load. Open ShareTexts in an up-to-date regular browser rather than a browser inside another app. If room creation still fails, the service may be unavailable; wait before trying again.

Hop will not link or receive

Keep both devices online while linking. Compare the four emoji and approve on the first device. Check the device clock if requests fail. If site data was cleared, the browser may need to be linked again.

Report a problem without sharing access

Contact @0xalyt on X with your device, browser, and the message shown. Do not post a room link, secret, space code, or private file.

Send a file to another device

Connect two browsers, send the original file, and save the received copy.

Choose this for a live handoff between phones, tablets, or computers. Both devices need internet access, but they do not need the same operating system or Wi-Fi network.

Connect, send, and save

  1. Open ShareTexts on both devices

    Visit sharetexts.online in each browser. You do not need an account.

  2. Connect with the current code

    On the device with the file, choose Send. On the receiving device, choose Receive and enter the six digits shown. A QR scan or room link also works.

  3. Choose the file

    Use the attachment control to select it. On a computer, you can also drag a file into the room. Keep both tabs open and the devices awake until progress finishes.

  4. Download the received copy

    Use the file’s download control on the receiving device. Allow downloads if asked. Check that the copy opens before deleting the original.

On these devices

Open the file after downloading it. A received message in a room is not the same as a file saved on the device.

If the transfer stops

Bring both tabs back into view and check the internet connection. If a transfer reports failure, use Retry. Try a small file to check the connection before retrying a large one. Browser memory, available storage, and network stability can limit large transfers.

What happens to your file

ShareTexts sends the selected file without compressing or converting it. Your phone’s picker may offer a converted version before ShareTexts receives the selection.

Live transfers are encrypted in transit, directly when possible or through a relay. The service issues the room secret and could derive its key. Closing the room does not remove files already downloaded or explicitly saved in a browser.

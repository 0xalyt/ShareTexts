How to send a file from iPhone to Windows

Open sharetexts.online on both devices. On the iPhone tap Send, then type the six-digit code on the PC. Pick the file. It arrives on the PC with a Save button. Nothing is installed on either side, and both devices must keep the tab open until the transfer finishes.

Quick answer: open sharetexts.online on both devices, tap Send on one, type the six-digit code on the other, pick the file. It arrives with a Save button.

Why this works without iTunes or a cable

The browser on each device opens one encrypted connection to the other. The file travels over that connection and never waits on a server. iTunes is only needed for backups and syncing, and a cable only moves files when both ends understand each other. Neither is involved here.

Step by step

  1. Open the site on both devices

    On the iPhone, open Safari and go to sharetexts.online. Do the same in Edge or Chrome on the PC.

  2. Tap Send on the iPhone

    A six-digit code and a QR code appear. Leave this screen open.

  3. Enter the code on the PC

    Type the six digits, or scan the QR with the iPhone if the PC did not start the room.

  4. Pick the file, then save it

    Choose the photo or file on the iPhone. On the PC it appears with a Save button.

What people usually send

Camera-roll photos, screenshots, PDFs from Mail, a link from Safari, a paragraph of text. All of it takes the same route. Photos arrive as ordinary JPEG or HEIC files, exactly as the iPhone stored them.

When it will not work

The iPhone must keep Safari in the foreground while the file sends. A Windows PC without Wi-Fi can still join if it has a wired connection. Very large videos over a weak mobile signal will be slow — that is the phone network, not the browser.

Questions people ask

Do I need iTunes on Windows?

No. iTunes is not used. The transfer happens between the two browsers.

Do I need to install anything on the iPhone?

No. Safari is enough, and nothing is added to the home screen unless you choose to install it.

Does it work away from home Wi-Fi?

Yes, if both devices have internet. The connection goes through the network each device is on, so a phone on mobile data can send to a PC on home broadband.

Where do the files go afterwards?

Downloads on the PC. Nothing is stored on a server after the transfer finishes, and a room closes when both tabs close.

Can I send a whole album at once?

Yes. Select several photos in the picker; they queue and arrive one after another.
